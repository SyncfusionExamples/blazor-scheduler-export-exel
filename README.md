# Blazor Scheduler Export Excel

A quick-start project demonstrating how to export appointments and calendar data to Excel format in the Blazor Scheduler Component. This sample showcases the complete export functionality with multiple export options and customization capabilities.

## Project Overview

This project provides a practical example of implementing Excel export features in Blazor Scheduler. It demonstrates best practices for exporting calendar events with all associated data to Excel workbooks, making it easy for users to archive or share scheduling information.

## Project Prerequisites

Make sure that you have the latest versions of 'Visual Studio 2022' installed on your machine before starting to work on this project. Ensure you have the required Syncfusion NuGet packages for Blazor Scheduler.

## How to Run This Application

1. Clone the `blazor-scheduler-export-exel` repository and open it in Visual Studio 2022.

2. Register the Syncfusion license key in the Program.cs file. If you have any doubts, check the documentation link: https://blazor.syncfusion.com/documentation/getting-started/license-key/how-to-register-in-an-application

3. Build and run your project to view the output in your default browser.

## Getting Started

This sample demonstrates the Export to Excel functionality of the Blazor Scheduler component. You can export events with all their properties, custom fields, and resource information directly to Excel format for reporting and data analysis purposes.
